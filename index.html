web-components-core

The reactive input model + BlissElement base class shared across the KeenMate web components. These pages are a manual visual harness for the parts that render — the /positioning helpers — served straight from src/ with no build step.

This is a library, not an app — there is no component to mount, so each example drives the helpers directly (and one small <tooltip-card> demo component shows the full BlissElement path). Nothing here ships in the published package.
