DH01 · Reorder: createPointerDrag

Drag a row to a new place — with a mouse, or with a finger: hold for 300 ms, then drag (moving earlier scrolls the list, as a phone user expects). Near the list's edge it auto-scrolls; Escape cancels. The hit test sees through shadow roots (deepElementFromPoint). The list's box clips its overflow, so the drag ghost is a layer (createLayer(this, { isInteractive: false }), DH03) — outside the component, never clipped, invisible to the hit test. 

import { createPointerDrag } from '@keenmate/web-components-core';

this.#drag = createPointerDrag(this.#list, {
  getSource: (target) => target.closest('li'),       // null = not draggable here
  longPressMs: 300,                                  // touch: hold, then drag
  onStart: ({ source }) => this.#canDrag(source),    // false refuses
  onMove: ({ target, x, y }) => this.#showDropIndicator(target, x, y),
  onDrop: ({ source, target }) => this.#move(source, target),
  onCancel: () => this.#hideDropIndicator(),         // Escape
});

DH02 · Files over the page: watchPageDrag

Drag a file from your desktop over any part of this page: the zone arms as soon as the files enter the window (not only when they reach it) and disarms when they leave, are dropped or the drag is cancelled. One shared set of window listeners serves every watcher; applyArmedState sets the armed attribute and :state(armed) on the host for the component's CSS. 

import { watchPageDrag, applyArmedState } from '@keenmate/web-components-core';

// connect()
this.#stopArmed = watchPageDrag({ types: ['Files'], onChange: (isArmed) => applyArmedState(this, this.internals, isArmed) });
// disconnect()
this.#stopArmed();

DH03 · Layers and drawers: createLayer, .km-drawer

A layer is a styled panel outside the component — its own shadow root with your CSS, in the overlay container, above the page (Z_INDEX), following the host's theme. place(rect) takes viewport coordinates. Here a "drop files here" cover is placed over the DH02 zone and 16 px beyond it — nothing around it can clip or cover it. A drawer is a modal panel on one edge: the .km-drawer km-drawer--<side> preset from SHEET_CHROME_CSS plus startModalSession (inert page, Tab trap, Escape / backdrop close) — or startPanelSession for a drawer the page stays usable around (Escape or a click outside closes it; no backdrop, nothing inert). --start / --end follow the writing direction.

drawer 
import { createLayer } from '@keenmate/web-components-core/positioning';
import { adoptStyles, SHEET_CHROME_CSS, startModalSession, animateOut } from '@keenmate/web-components-core';

const layer = createLayer(this, { css: COVER_CSS, className: 'dz-cover' });
layer.element.textContent = 'Drop files here';
layer.place(this.getBoundingClientRect());
layer.destroy();

adoptStyles(this.shadowRoot, SHEET_CHROME_CSS);
panel.classList.add('km-drawer', 'km-drawer--end');
const session = startModalSession(panel, { backdrop: true, onDismiss: () => close() });
const close = () => { session.end(); animateOut([panel], { className: 'km-drawer--closing', onDone: () => panel.remove() }); };

DH04 · Clipboard: copyText and readPasteText

copyText(text) uses the Clipboard API and falls back to a hidden, selected textarea + execCommand('copy') (an http page, an old browser); it resolves true / false and never throws. readPasteText(event) reads text/plain from a paste and turns Windows line ends into \n — a block copied from Excel arrives as rows of tab-separated cells. Copy the table, then paste into the box below. 

import { copyText, readPasteText } from '@keenmate/web-components-core';

const isCopied = await copyText(rows.map((r) => r.join('\t')).join('\n'));
cell.addEventListener('paste', (e) => {
  const text = readPasteText(e);             // text/plain, CRLF → LF
  if (!text) return;
  e.preventDefault();
  this.#pasteBlock(text.split('\n').map((line) => line.split('\t')));
});

DH05 · Icon strings: renderIcon

An item's icon is data, read with one rule: markup (it starts with <) goes in raw, an ASCII name becomes a .km-icon glyph masked from the --base-icon-<name> token in currentColor (this page defines star and check; an unknown name draws nothing), anything else (an emoji, a letter) is escaped text. ICON_CSS is the drawing rule.

rendered 

            

            
import { renderIcon, ICON_CSS, adoptStyles } from '@keenmate/web-components-core';

adoptStyles(this.shadowRoot, ICON_CSS);
cell.innerHTML = renderIcon(item.icon, { prefix: 'grid' });

        


        
        
        
        

            
DH06 · Render callbacks: renderSlot

            

                Every render*Callback that returns content is read the same way: a string is HTML, a node
                is mounted, null draws the built-in look, false hides the slot. The three cards
                below repaint every 500 ms, like a busy grid. Pick "an input", type into it and watch: with
                memoKey the hook isn't even called while the key is the same; without it the hook runs on
                every repaint, but a same string isn't rewritten — the input keeps its focus and value either way.
                "a new node" returns a fresh element each time: that one does lose focus without a key.
            

            

                the hook returns
                
                
                
                
                
                
            

            

                

                

                

            

            

            
import { renderSlot } from '@keenmate/web-components-core';

renderSlot(cellEl, () => this.config.renderCellCallback?.(this.withContext({ row, column })), {
  memoKey: `${row.id}@${row.version}@${column.field}`,   // unchanged → the hook isn't even called
  renderDefault: (el) => (el.textContent = format(row[column.field])),
});
// string → HTML · Node → mounted · null / undefined → renderDefault · false → hidden

        


        
        
        
        

            
DH07 · The controller: createControllerFacade

            

                el.controller (and detail.controller on every event) is the component's public
                API, not its engine: a frozen object with the listed methods and state, reading the engine lazily. Before
                the first build it answers with the declared defaults (count: 0, increment() →
                -1) instead of throwing; the engine's other members aren't reachable.
            

            

                
                
                
                
            

            

            

            
import { createControllerFacade } from '@keenmate/web-components-core';

protected override createController() {
  return createControllerFacade(() => { this.flush(); return this.#engine; }, {
    methods: ['increment', 'reset'],
    state: { count: 0 },                         // answered before the first build
    emptyResults: { increment: () => -1 },
  });
}

        


        
        
        
        

            
DH08 · API summary

            

                
APIWhat it does

                
                    
createPointerDrag(container, { getSource, threshold, longPressMs, autoScroll, onStart, onMove, onDrop, onCancel })Mouse + touch drags inside a component: threshold, touch long press, edge auto-scroll, Escape; the context has source, x, y, target (through shadow roots), pointerType. Returns { isDragging, cancel, destroy }.

                    
deepElementFromPoint(document, x, y)The innermost element at a point, through open shadow roots.

                    
watchPageDrag({ types, onChange }) · applyArmedState(host, internals, isArmed)Files (or other types) dragged over the window, one shared listener set; returns a stop function. The armed attribute + :state(armed).

                    
createLayer(host, { css, className, zIndex, isInteractive, container }) (/positioning)A themed panel in the overlay container with its own shadow root: { element, layer, place(rect), syncTheme, destroy }.

                    
startPanelSession(panel, { onDismiss, shouldCloseOnEscape, shouldCloseOnOutsideClick, shouldCloseOnBack, trigger, initialFocus })A non-modal panel: Escape / a click outside / Back → onDismiss(reason); no backdrop, inert page or focus trap. { end, rearmBack, isEnded }.

                    
.km-drawer · --start / --end / --top / --bottom / --closing (SHEET_CHROME_CSS)An edge drawer; --km-sheet-drawer-size / -max-height / -bg / -color / -shadow / -border-radius / -duration.

                    
copyText(text) · readPasteText(event, { type, shouldNormalizeNewlines })Copy with the Clipboard API or the execCommand fallback (→ Promise<boolean>); a paste's text, CRLF → LF.
