DH01 · Reorder: createPointerDrag

Drag a row to a new place — with a mouse, or with a finger: hold for 300 ms, then drag (moving earlier scrolls the list, as a phone user expects). Near the list's edge it auto-scrolls; Escape cancels. The hit test sees through shadow roots (deepElementFromPoint). The list's box clips its overflow, so the drag ghost is a layer (createLayer(this, { isInteractive: false }), DH03) — outside the component, never clipped, invisible to the hit test. 

import { createPointerDrag } from '@keenmate/web-components-core';

this.#drag = createPointerDrag(this.#list, {
  getSource: (target) => target.closest('li'),       // null = not draggable here
  longPressMs: 300,                                  // touch: hold, then drag
  beforeStartCallback: ({ source }) => this.#canDrag(source),    // false refuses
  moveCallback: ({ target, x, y }) => this.#showDropIndicator(target, x, y),
  dropCallback: ({ source, target }) => this.#move(source, target),
  cancelCallback: () => this.#hideDropIndicator(),         // Escape
});

DH02 · Files over the page: observePageDrag

Drag a file from your desktop over any part of this page: the zone arms as soon as the files enter the window (not only when they reach it) and disarms when they leave, are dropped or the drag is cancelled. One shared set of window listeners serves every watcher; setDropActiveState sets the drop-active attribute and :state(drop-active) on the host for the component's CSS. 

import { observePageDrag, setDropActiveState } from '@keenmate/web-components-core';

// connect()
this.#stopDropActive = observePageDrag({ types: ['Files'], changeCallback: (isDropActive) => setDropActiveState(this, this.internals, isDropActive) });
// disconnect()
this.#stopDropActive();

DH03 · Layers, drawers and the full-screen sheet: createLayer, .km-drawer, .km-sheet

A layer is a styled panel outside the component — its own shadow root with your CSS, in the overlay container, above the page (Z_INDEX), following the host's theme. place(rect) takes viewport coordinates. Here a "drop files here" cover is placed over the DH02 zone and 16 px beyond it — nothing around it can clip or cover it. A drawer is a modal panel on one edge: the .km-drawer km-drawer--<side> preset from SHEET_CHROME_CSS plus startModalSession (inert page, Tab trap, Escape / backdrop close) — or startPanelSession for a drawer the page stays usable around (Escape or a click outside closes it; no backdrop, nothing inert). --start / --end follow the writing direction. A full-screen sheet (a phone picker) is the .km-sheet frame from the same stylesheet: the whole screen, content kept out of the notch / home-bar safe areas, the core header (createSheetHeader) on top and .km-sheet-body scrolling under it — always with startModalSession.

drawer 
import { createLayer } from '@keenmate/web-components-core/positioning';
import { adoptStyles, SHEET_CHROME_CSS, startModalSession, animateOut } from '@keenmate/web-components-core';

const layer = createLayer(this, { css: COVER_CSS, className: 'dz-cover' });
layer.element.textContent = 'Drop files here';
layer.place(this.getBoundingClientRect());
layer.destroy();

adoptStyles(this.shadowRoot, SHEET_CHROME_CSS);
panel.classList.add('km-drawer', 'km-drawer--end');
const session = startModalSession(panel, { backdrop: true, dismissCallback: () => close() });
const close = () => { session.end(); animateOut([panel], { className: 'km-drawer--closing', doneCallback: () => panel.remove() }); };

// a phone full-screen sheet: header + scrolling body, the keyboard shrinks it
sheet.classList.add('km-sheet');
body.classList.add('km-sheet-body');
sheet.replaceChildren(createSheetHeader({ title: 'Pick a city', closeLabel: 'Close', closeCallback: () => close() }).header, body);
const session = startModalSession(sheet, { dismissCallback: () => close(), shouldFitToVisibleViewport: true });
// close: session.end(); animateOut([sheet], { className: 'km-sheet--closing', doneCallback: () => sheet.remove() });

DH04 · Clipboard: copyText and readPasteText

copyText(text) uses the Clipboard API and falls back to a hidden, selected textarea + execCommand('copy') (an http page, an old browser); it resolves true / false and never throws. readPasteText(event) reads text/plain from a paste and turns Windows line ends into \n — a block copied from Excel arrives as rows of tab-separated cells. Copy the table, then paste into the box below. 

import { copyText, readPasteText } from '@keenmate/web-components-core';

const isCopied = await copyText(rows.map((r) => r.join('\t')).join('\n'));
cell.addEventListener('paste', (e) => {
  const text = readPasteText(e);             // text/plain, CRLF → LF
  if (!text) return;
  e.preventDefault();
  this.#pasteBlock(text.split('\n').map((line) => line.split('\t')));
});

DH05 · Icon strings: renderIcon

An item's icon is data. Every component reads it the same way, first match wins:

  1. markup (it starts with <) goes in raw;
  2. a built-in name (close, chevron, check, … BUILT_IN_ICON_NAMES) is a .km-icon glyph masked from its --base-icon-<name> token in currentColor — reserved, the hook never sees it (this page defines only check, so close draws nothing here);
  3. the element's own renderIconCallback(name, ctx) (here moon → an SVG), then the page-wide window.components.renderIconCallback (here star) — each answers null for a name that isn't its own; one element needs no page setup;
  4. other class names are an icon font: <i class="demo__icon fa-solid fa-folder"> (demo-font-heart stands in for Font Awesome here);
  5. anything else (an emoji, a letter) is escaped text.

// one element — asked first, null = not mine

    name === 'star' ? '<svg viewBox="0 0 24 24" width="1em" height="1em">…</svg>' : null; // null = not mine

DH06 · Render callbacks: renderSlot

            

                Every render*Callback that returns content is read the same way: a string is HTML, a node
                is mounted, null draws the built-in look, false hides the slot. The three cards
                below repaint every 500 ms, like a busy grid. Pick "an input", type into it and watch: with
                memoKey the hook isn't even called while the key is the same; without it the hook runs on
                every repaint, but a same string isn't rewritten — the input keeps its focus and value either way.
                "a new node" returns a fresh element each time: that one does lose focus without a key.
            

            

                the hook returns
                
                
                
                
                
                
            

            

                

                

                

            

            

            
import { renderSlot } from '@keenmate/web-components-core';

renderSlot(cellEl, () => this.config.renderCellCallback?.(this.withContext({ row, column })), {
  memoKey: `${row.id}@${row.version}@${column.field}`,   // unchanged → the hook isn't even called
  renderDefault: (el) => (el.textContent = format(row[column.field])),
});
// string → HTML · Node → mounted · null / undefined → renderDefault · false → hidden

        


        
        
        
        

            
DH07 · The controller: createControllerFacade

            

                el.controller (and detail.controller on every event) is the component's public
                API, not its engine: a frozen object with the listed methods and state, reading the engine lazily. Before
                the first build it answers with the declared defaults (count: 0, increment() →
                -1) instead of throwing; the engine's other members aren't reachable.
            

            

                
                
                
                
            

            

            

            
import { createControllerFacade } from '@keenmate/web-components-core';

protected override createController() {
  return createControllerFacade(() => { this.flush(); return this.#engine; }, {
    methods: ['increment', 'reset'],
    state: { count: 0 },                         // answered before the first build
    emptyResults: { increment: () => -1 },
  });
}

APIWhat it does

                
                    
createPointerDrag(container, { getSource, threshold, longPressMs, autoScroll, beforeStartCallback, moveCallback, dropCallback, cancelCallback })Mouse + touch drags inside a component: threshold, touch long press, edge auto-scroll, Escape; the context has source, x, y, target (through shadow roots), pointerType. Returns { isDragging, cancel, destroy }.

                    
deepElementFromPoint(document, x, y)The innermost element at a point, through open shadow roots.

                    
observePageDrag({ types, changeCallback }) · setDropActiveState(host, internals, isDropActive)Files (or other types) dragged over the window, one shared listener set; returns a stop function. The drop-active attribute + :state(drop-active).

startPanelSession(panel, { dismissCallback, shouldCloseOnEscape, shouldCloseOnOutsideClick, shouldCloseOnBack, trigger, initialFocus })A non-modal panel: Escape / a click outside / Back → dismissCallback(reason); no backdrop, inert page or focus trap. { end, rearmBack, isEnded }.

                    
.km-drawer · --start / --end / --top / --bottom / --closing (SHEET_CHROME_CSS)An edge drawer; --km-sheet-drawer-size / -max-height / -bg / -color / -shadow / -border-radius / -duration.

                    
.km-sheet · .km-sheet-body · --closing (SHEET_CHROME_CSS)The phone full-screen sheet frame (fixed, 100dvw × 100dvh, safe areas, modal tier, header + scrolling body); --km-sheet-bg / -color / -z-index / -duration / -enter-offset.
