AN01 · Positioning a bare element

anchor() positions any floating element against a reference and keeps it there across scroll/resize (autoUpdate). Change the placement or offset — the box repositions live.

reference element

A floating box is anchored to it (it follows on scroll).

AN02 · Size caps (maxHeight / maxWidth)

The size() middleware caps the floating element to the space available in the viewport, so an over-tall or over-wide panel scrolls instead of overflowing. The panel below has 30 rows that don't wrap — taller and wider than the window. Toggling a cap rebuilds the open panel.

flip runs before the cap: when the panel fits neither side, it opens on the side with more room (often above). maxHeight then fits it to that side. Without maxWidth the rows run off the right edge; with it the panel stops at the edge and scrolls sideways.

AN03 · Drift detection (onDrift)

A position: fixed element is placed against the viewport — unless an ancestor makes a containing block for it (transform, filter, a matching will-change, contain: paint, …). Then the browser measures its left / top from that ancestor. If the positioning code didn't account for it, the panel lands off its anchor. onDrift reports that case: after each placement core measures where the panel really is, and calls onDrift only when it is 1.5px or more off.

The panel below is a child of the transformed box. Floating UI's default platform sees the transform and places it correctly, so no drift. To show a report, the first mode simulates a containing block the heuristic misses: a custom platform whose getOffsetParent always answers window.

The fix
Pass shouldUseFixedContainingBlock: true (or your own platform) so anchor() takes the offset parent from the floating element's own containing-block ancestor. web-multiselect uses this. If a containing block is still missed, onDrift tells you and names the likely culprit — log it once.

AN04 · API summary

import { anchor } from '@keenmate/web-components-core/positioning';

const handle = anchor(floating, reference, {   // reference: Element or VirtualElement
  placement: 'bottom-start',
  offset: 4,
  matchWidth: 'min',
  maxHeight: { padding: 8 },
  lockPlacement: 'freeze',
  onDrift(report) { console.warn('panel drifted', report); },
});

handle.update();   // reposition now
handle.destroy();  // stop autoUpdate, restore the copied data-theme
