Anchor primitive

The low-level anchor(floating, reference, opts) that createTooltip and createPopover are built on — offset / flip / shift middleware, width matching, size caps, placement locking, and drift detection.

AN01 · Positioning a bare element

anchor() positions any floating element against a reference and keeps it there across scroll/resize (autoUpdate). Change the placement or offset — the box repositions live.

reference element

A floating box is anchored to it (it follows on scroll).

AN02 · Size caps (maxHeight / maxWidth)

The size() middleware caps the floating element to the space available between the reference and the viewport edge, so an over-tall or over-wide panel scrolls instead of overflowing. Toggle the caps and reopen.

reference

AN03 · Drift detection (onDrift)

A position: fixed element is positioned relative to the viewport — unless an ancestor establishes a containing block (a CSS transform, filter, will-change, …). Then it silently drifts off its anchor. anchor() can detect that: the reference below lives inside a transformed box, so after positioning the onDrift callback reports how far the panel actually landed from where it was placed.

The fix
Pass fixedContainingBlock: true (or a custom platform) so anchor() resolves the offset parent from the floating element's own transformed ancestor — this is the escape hatch components like web-multiselect use.

AN04 · API summary

import { anchor } from '@keenmate/web-components-core/positioning';

const handle = anchor(floating, reference, {
  placement: 'bottom-start',
  strategy: 'fixed',               // default 'fixed'
  offset: 4,
  flip: true, shift: 8,            // middleware (offset → size → flip → shift)
  matchWidth: 'min',              // 'min' | 'exact'
  maxHeight: { padding: 8 },      // size() cap to available height
  maxWidth: { padding: 8 },       // size() cap to available width
  lockPlacement: 'freeze',        // true | 'freeze'
  fixedContainingBlock: true,     // resolve offset parent from a transformed ancestor
  beforeCompute() {},             // per-frame hook (publish a CSS var, clamp, …)
  onPlaced(p) {}, onComputed(c) {}, onDrift(report) {},
});

handle.update();   // reposition now
handle.destroy();  // stop autoUpdate + clean up
