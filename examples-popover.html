Popovers

The createPopover() preset — a portaled dropdown/panel anchored to a reference, with width-matching and placement locking. The dropdown shape the five components used to re-wrap ~15 different ways.

PO01 · Playground

One popover, every option live. createPopover({ reference, panel }) returns { open, close, isOpen, destroy }; the panel is portaled to <body> and positioned by anchor(). Change any control — the popover rebuilds with the new options (and reopens if it was open). Open it, then scroll it near the bottom edge to watch flip and lockPlacement: 'freeze' behave.

matchWidth: what to look for
With the 360px reference and the long content toggle, watch all four: none = natural content width (ignores the reference); min = at least 360px (grows for wider content); max = at most 360px (shrinks for narrower content, wraps when wider); exact = always 360px. So with the content narrower than 360px, none=max (both narrow) and min=exact (both 360px); with the content wider, it flips: none=min (both grow) and max=exact (both clamp to 360px). min = max(reference, content), max = min(reference, content).

PO02 · API summary

import { createPopover } from '@keenmate/web-components-core/positioning';

const pop = createPopover({
  reference,                 // element (or VirtualElement) to anchor to
  panel,                     // the panel element to position + portal
  placement: 'bottom-start', // default 'bottom-start'
  offset: 4,                 // px gap (default 4)
  matchWidth: 'min',         // 'min' | 'exact' — size to the reference width
  lockPlacement: 'freeze',   // true = return to initial on overflow; 'freeze' = flip once then pin
  container: document.body,  // mount target (default body)
  flip: true, shift: 8,      // middleware toggles
  onPlaced(placement) {},    // resolved placement callback
});

pop.open(); pop.close(); pop.isOpen; pop.destroy();
