PO01 · Playground

One popover, every option live. createPopover({ reference, panel }) returns { open, close, update, isOpen, destroy }; the panel is portaled to <body> and positioned by anchor(). Change any control — the popover rebuilds with the new options (and reopens if it was open). Open it, then scroll it near the bottom edge to watch flip and lockPlacement: 'freeze' behave. It closes on Escape or a click outside (shouldCloseOnEscape / shouldCloseOnOutsideClick).

matchWidth: what to look for
With the 360px reference and the long content toggle, watch all four: none = natural content width (ignores the reference); min = at least 360px (grows for wider content); max = at most 360px (shrinks for narrower content, wraps when wider); exact = always 360px. So with the content narrower than 360px, none=max (both narrow) and min=exact (both 360px); with the content wider, it flips: none=min (both grow) and max=exact (both clamp to 360px). min = max(reference, content), max = min(reference, content).

PO02 · API summary

import { createPopover } from '@keenmate/web-components-core/positioning';

const pop = createPopover({
  reference,                 // element (or VirtualElement) to anchor to
  panel,                     // the panel element to position + portal
  container,                 // default: the open modal <dialog> / :popover-open around the reference, else body
  shouldCloseOnEscape: true,       // close on Escape (deepest open overlay only), focus back to the reference
  shouldCloseOnOutsideClick: true, // close on a press outside the panel and the reference
  overlayGroup: 'menus',     // opening another overlay of the group closes this one
  onClose(reason) {},        // it closed itself: Escape, outside press, another overlay

  // Every anchor() option is forwarded as given:
  placement: 'bottom-start', // default 'bottom-start'
  offset: 4,                 // px gap (default 4)
  matchWidth: 'min',         // 'min' | 'exact' | 'max' | false — size against the reference width
  lockPlacement: 'freeze',   // true = return to initial on overflow; 'freeze' = flip once then pin
  shouldFlip: true, shift: 8, // middleware toggles
  onPlaced(placement) {},    // resolved placement callback
});

pop.open(); pop.close(); pop.update(); pop.isOpen; pop.destroy();

inheritThemeFrom defaults to the reference. See the anchor page for every forwarded option.
