Page-wide controls

What a page gets from core across every KeenMate component on it: the window.components registry (SPEC §12.3), the logging switches — per tag, per instance and page-wide (§12.1), the shared loader hook (§12.14) and the style-injection helpers (§12.8). The demos use <core-demo-pg>, registered with registerComponent() and a createLoggers('PGDEMO') bundle, and <core-demo-pg-early>, registered with no bundle. Everything the page changes globally is undone by Reset page-wide state and on pagehide.

PG01 · The window.components registry

registerComponent(tag, Class, { config, logging?, shouldAutoDefine? }) publishes one entry per tag — version(), config, logging (the bundle's controls, when a bundle was passed), register() and getInstances() — and defines the element (unless shouldAutoDefine: false; then register() does it, idempotently). An entry the page created before the script loaded is adopted: the same object gains the registry members and keeps its own keys. Instances are tracked by BlissElement itself, on connect / disconnect (a DOM move re-tracks the same element, no duplicate), so getInstances(tag) and getRegisteredTags() (tags with at least one connected instance) need no per-component bookkeeping. The page-wide logging, renderLoadingCallback and responsive* members are non-enumerable, so Object.keys(window.components) still lists tags only. 


            

            
<script>  // before any module
  window.components = { 'core-demo-pg-early': { note: 'set by the page before core loaded' } };
</script>

const pgLogging = createLoggers('PGDEMO');
registerComponent('core-demo-pg', CoreDemoPg, {
  config: { name: 'core-demo-pg', version: '0.0.0-demo' }, logging: pgLogging });
registerComponent('core-demo-pg-early', CoreDemoPgEarly, {
  config: { name: 'core-demo-pg-early', version: '0.0.0-demo' }, shouldAutoDefine: false });

Object.keys(window.components);                 // ['core-demo-pg-early', 'core-demo-pg'] — tags only
window.components['core-demo-pg'].getInstances();   // the live, connected elements
getRegisteredTags();                            // tags with ≥ 1 connected instance
window.components['core-demo-pg-early'].note;   // kept — the entry was adopted, not replaced
window.components['core-demo-pg-early'].register();  // customElements.define now → markup upgrades

        


        
        
        
        

            
PG02 · Logging: per tag, per instance, page-wide

            

                createLoggers(namespace, categories?) returns one colour-prefixed
                NAMESPACE:CATEGORY logger per category (default INIT / DATA /
                UI). The closest level wins: element → component type → page → warn. Nothing is
                set by default, so warnings and errors show and debug/info need enableLogging() (default level
                debug) at some layer; disableLogging() sets a layer to silent,
                resetLogging() clears it. Inside a component, this.log.<CATEGORY> prefixes each
                line with the instance (#id) — el.enableLogging(level?) makes one element louder
                or quieter than its type. Core never calls console directly: its own messages (invalid attribute
                values → INIT, actions / menus / twins → UI) go through the element's logger, or
                core's CORE bundle (ELEMENT / ACTIONS / MENU /
                THEME) for a tag with no bundle. The page-wide switch
                window.components.logging sets a level on every bundle, CORE included, and on
                bundles created later; a later per-tag call wins for that tag. The bundle controls never persist; only an
                explicit logger.setLevel(x) writes localStorage. The log below captures the
                console lines each button produced.

PG03 · The shared loader

            

                Components draw every loading state with
                renderLoader(host, container, context, { label, prefix }), which returns an idempotent
                remove(). Precedence, highest first: the instance
                renderLoadingCallback (same name in every component, read from the host), then the
                page-wide window.components.renderLoadingCallback, then the
                default <span class="<prefix>-loader" aria-hidden="true">, which the
                component draws with its own CSS — core ships none; the demo copies SPEC §12.14's drawing rule with
                --pgd-loader-* tokens chained to --base-loader-*. Only the highest present hook
                runs; a hook that throws is logged and the default is drawn instead, so a loading state is never blank.
                Hooks get { component, context, containerElement, element, label } and may return a cleanup.
                The container always gets role="status" (+ aria-label); remove()
                runs the cleanup, removes what the render added and restores the previous attributes. The page hook is a
                non-enumerable accessor shared by every bundled core copy; a plain value assigned before any component
                loaded is adopted.

What "throws" simulates

                A broken app hook — e.g. B's renderLoadingCallback calls a spinner library that didn't load,
                or looks up an element that isn't there. Core catches the error, logs
                renderLoadingCallback threw — drawing the default loader, removes anything the hook managed to
                add, and draws its default spinner, keeping role="status" + the label, so the
                user still sees (and a screen reader still announces) that B is loading. Note it falls back to the
                default, not to the page hook: only the highest hook that's set runs, so with "page hook"
                ticked, A shows the dots while B shows the default spinner.

startLoading() { this.#remove = renderLoader(this, this.statusEl, 'overlay', { label: 'Loading…', prefix: 'pgd' }); }
stopLoading()  { this.#remove?.(); }

// page side — every component's loaders, one look (inside shadow DOM: style inline / SVG)
window.components.renderLoadingCallback = ({ component, context, containerElement }) => {
  containerElement.insertAdjacentHTML('beforeend', '<svg …>three animated dots</svg>');
};
// one instance — beats the page hook; the returned cleanup runs on remove()
elB.renderLoadingCallback = ({ containerElement, label }) => {
  const timer = setInterval(tick, 100);
  return () => clearInterval(timer);
};
window.components.renderLoadingCallback = null;     // a non-function reads as unset

        


        
        
        
        

            
PG04 · Style injection: adoptStyles() / createStyleSlot()

            

                Two free functions, because core itself doesn't assume shadow DOM. adoptStyles(root, ...css)
                is for static CSS (the main.css?inline case): one cached
                CSSStyleSheet per unique string, shared by every instance through
                adoptedStyleSheets and deduplicated per root (with a <style> fallback where
                constructable sheets aren't supported). createStyleSlot(root, { position?, cssClass? }) returns
                { set, clear, destroy }, a per-instance replaceable <style> for
                the customStylesCallback pattern: setting it again replaces the CSS in the same element (no
                stacking), and a falsy value removes it. It is a <style> on purpose, because user CSS may use
                @import, which constructable sheets reject.
            

            

                
                
                
            

            

                

            

            
reinit() {
  const root = this.shadowRoot ?? this.attachShadow({ mode: 'open' });
  adoptStyles(root, SHARED_CSS);                       // one sheet, shared by A and B
  this.#slot ??= createStyleSlot(root, { cssClass: 'pgd-custom' });
  this.#slot.set(this.config.customStylesCallback?.());
}
update(p) { if ('customStylesCallback' in p) this.#slot.set(this.config.customStylesCallback?.()); }

a.shadowRoot.adoptedStyleSheets[0] === b.shadowRoot.adoptedStyleSheets[0];   // true
a.shadowRoot.querySelectorAll('style.pgd-custom').length;                    // 1, however often it is set

        


        
        
        
        

            
PG05 · API summary

            

                
APIWhat it does

                
                    
registerComponent(tag, Class, { config, logging?, shouldAutoDefine? })Publishes window.components[tag] (adopting an existing entry), defines the element (unless shouldAutoDefine: false), wires the bundle to instance loggers. Returns the entry.

                    
entry.version() · config · logging · register() · getInstances()Build metadata, the bundle's controls (enableLogging / disableLogging / setLogLevel / resetLogging / setCategoryLevel / getCategories), idempotent define, live instances. Plus per-tag responsive / responsiveCallback (SPEC §6.7).

                    
getInstances(tag) · getRegisteredTags()Connected elements of a tag (connection order); tags with at least one connected instance.

                    
createLoggers(namespace, categories?)A LoggerBundle: loggers, enableLogging(level = 'debug'), disableLogging(), setLogLevel(), resetLogging(), setCategoryLevel(), forInstance(). Nothing set → warn (DEFAULT_LOG_LEVEL).

                    
this.log.<CATEGORY>Protected instance loggers: [NS:CAT] #id; a tag with no bundle → [CORE:ELEMENT] tag#id.

                    
el.enableLogging(level?) · el.disableLogging() · el.resetLogging() · el.isLoggingEnabledThe element's own level; it wins over its type and the page (louder or quieter).

                    
window.components.logging / getGlobalLogging()The page level (enableLogging / disableLogging / setLogLevel / resetLogging / getCategories) for every bundle, CORE included, and later ones, wherever a type has no own level. Non-enumerable; state on globalThis.

                    
coreLogging · getCoreLogging() · CORE_LOG_CATEGORIESCore's own bundle: CORE:ELEMENT / ACTIONS / MENU / THEME, created on first use (importing core has no side effect).

                    
renderLoader(host, container, context, { label, prefix, renderLoadingCallback? })Draws a loading state (instance hook > page hook > default span) and returns an idempotent remove().

                    
window.components.renderLoadingCallbackPage-wide loader hook (non-enumerable accessor; a non-function reads as unset).

                    
adoptStyles(root, ...css)Shared, cached constructable sheets; deduplicated per root.

                    
createStyleSlot(root, { position?, cssClass? })A replaceable per-instance <style>: set(css) / clear() / destroy().
