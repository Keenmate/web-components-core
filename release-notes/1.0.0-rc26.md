# Web Components Core 1.0.0-rc26 — Release Notes

**Released:** 2026-11-23 · **Pre-release** (`npm install @keenmate/web-components-core@rc`)

These notes cover the changes since **1.0.0-rc25**, the last version on npm. Upgrading from an older rc? Read the
[1.0.0-rc25](1.0.0-rc25.md) and [1.0.0-rc24](1.0.0-rc24.md) notes first.

rc26 is the naming release: core's public API gets its final v1 names from the naming review — verb-first
functions, `*Callback` for every hook passed in an options bag, one entry point per symbol — **renamed outright,
with no aliases**. Alongside it more component copies move into core (icon maps, the `.km-sheet` frame, layer custom
styles, the custom-CSS lint, engine defaults, a locale collator) and the overlays get stricter (a modal closes the
page's dropdowns, tooltips hide on scroll, the `/menu` phone sheet is modal). **Apps on the released components need
nothing**; component authors apply the rename tables below when they bump.

The exhaustive, per-change list is in
[`CHANGELOG.md`](https://github.com/KeenMate/web-components-core/blob/v1.0.0-rc26/CHANGELOG.md#100-rc26---2026-11-23)
(section 1.0.0-rc26); this document is the upgrade guide and the highlights.

## Upgrade checklist

**Component authors — renames (the type check guides you)**

- [ ] Rename the functions, constants and types in the rename table: `onTextInput` → `observeTextInput`,
      `watchPageDrag` → `observePageDrag`, `getLocaleSettings` → `resolveLocaleSettings`, `getMenuChildren` →
      `loadMenuChildren`, `createStyleSlot` → `createStyleElement`, `composedClosest` → `deepClosest`, …
      ([table](#renamed-functions-constants-and-types)).
- [ ] Batch writes: `el.setAttributes(values)` → `el.setProperties(values)`; protected `this.engineConfig()` →
      `this.getEngineConfig()`; protected `runHook()` → `runCallback()` ([details](#setattributes-is-now-setproperties)).
- [ ] Rename every options-bag hook from `on*` to `*Callback` — `anchor` / `createPopover` / `createTooltip`,
      `openMenu`, `createSheetHeader`, the modal / panel / sheet sessions, `animateOut`, `createAsyncRunner`,
      `createCustomStyles`, `observePageDrag`, `createPointerDrag` (`onStart` → `beforeStartCallback`), `/a11y`,
      `prepareSearchTerm`, `createSelection` ([table](#options-bag-hooks-are-callback)).
- [ ] Fix imports whose entry point changed: `createFocusTrap` / `getTabbables` / `FocusTrap` /
      `FocusTrapOptions` from `/a11y` (not the main index); `escapeHtml` from the main index (not `/search`); type
      `ComponentContext` from the main index (not `/actions`) ([details](#one-entry-point-per-symbol)).
- [ ] Replace removed exports: `resolveEnumAttribute` → a `toEnum` converter; `coreLogging` → `getCoreLogging()`;
      `toLogLevelNumber` → `isLogLevel` / `LOG_LEVELS`; drop imports of `defaultEventProperty`,
      `normalizeEventDefs`, `publishLoaderHook`, `publishIconHook`, `publishLocaleHooks`, type `ScrollLockState`
      ([details](#removed-exports)).
- [ ] Selection: `Selection` → `KeySelection`, `SelectionMode` → `KeySelectionMode`, and pass
      `mode: 'multiple'` instead of `'multi'` to `createSelection` ([details](#selection-types-and-the-multiple-mode)).
- [ ] State store: replace `createStateStore({ getKey, getLoadCallback, getSaveCallback })` with
      `createStateStore({ getConfig: () => this.config })` ([details](#createstatestore-takes-one-getconfig)).
- [ ] Drop targets: `applyArmedState(host, internals, isArmed)` → `setDropActiveState(host, internals,
      isDropActive)`; rename CSS `[armed]` / `:state(armed)` to `[drop-active]` / `:state(drop-active)`
      ([details](#armed-is-now-drop-active)).
- [ ] Viewport fitting: `observeKeyboardInset(panel)` → `fitToVisibleViewport(panel)`; session option
      `shouldObserveKeyboardInset` → `shouldFitToVisibleViewport` ([table](#renamed-functions-constants-and-types)).

**Component authors — behaviour to check**

- [ ] Modals: remove your own `dismissAllOverlays()` call before `startModalSession()` — the session now closes the
      page's default-group overlays itself; pass `shouldDismissPageOverlays: false` to keep them open
      ([details](#startmodalsession-dismisses-the-pages-overlays)).
- [ ] Tooltips that must follow a scrolling target while hovered: pass `shouldHideOnScroll: false` to
      `createTooltip`; otherwise drop your own scroll listener that hid them ([details](#tooltips-hide-on-scroll)).
- [ ] Labels: a key with neither a built-in default nor a `fallback` now renders the key itself (was `''`); add the
      missing `DEFAULT_LABELS` entry or pass `{ fallback }` ([details](#a-missing-label-shows-its-key)).
- [ ] `/menu` phone sheet / drawer: it is now modal (page inert, Tab trapped, Tab no longer closes it); update a
      test that tabbed out of an open sheet ([details](#the-menu-phone-sheet-is-modal)).
- [ ] `createAsyncRunner().run()` now returns a boolean: check code that relied on `void`
      ([details](#createasyncrunner-run-returns-a-boolean)).
- [ ] An object input that must refuse `null`: give `toObject()` a default — without one, `null` is now "unset"
      ([details](#toobject-accepts-null-without-a-default)).
- [ ] `bindShortcuts` bindings with `isEnabled()`: it now receives the `KeyboardEvent` and runs only for the matched
      binding; a `false` no longer consumes the key ([details](#bindshortcuts-isenabled-gets-the-event)).

**Component authors — adopt (optional, replaces your copies)**

- [ ] Icon maps (`icons` input with `isIconMap`, `renderIcon(…, { defaults })`, `openMenu(…, { iconDefaults })`),
      `.km-sheet`, `createLayer({ customStylesOptions })`, `createCustomStyles({ lintCssVars })`,
      `getInputDefaults()`, `getCollator()`, `createRovingFocus({ boundaryCallback })`, `createPointerDrag`'s
      `pressEvent`, `deepClosest` / `isDeepInside` / `runSafely` / `notifyListeners` ([details](#new-features)).
- [ ] Regenerate `custom-elements.json` so `controller`, `on()` and `isLoggingEnabled` are listed
      ([details](#fixes)).

**App developers**

- [ ] Nothing required on the released components: core's renames reach you through each component's own release.
- [ ] Page CSS that styled a drop target's `[armed]` / `:state(armed)`: rename to `[drop-active]` /
      `:state(drop-active)` once the component ships on rc26 ([details](#armed-is-now-drop-active)).
- [ ] Optional: map icon names page-wide with `window.components.icons = { close: 'fa-solid fa-xmark' }`
      ([details](#icon-maps)).

## Breaking changes

### Renamed functions, constants and types

Verb-first, qualified names from the naming review: `observe*` subscribes, `get*` reads, `create*` builds,
`resolve*` derives from page + instance, `load*` is async. No aliases — the v1 rcs don't keep old names.

| Was | Now |
|---|---|
| `onTextInput` | `observeTextInput` |
| `onOverlayActivated` | `observeOverlayActivation` |
| `watchPageDrag` / `WatchPageDragOptions` | `observePageDrag` / `ObservePageDragOptions` |
| `statelessRegex` (`/search`) | `createStatelessRegex` |
| `stateStorageKey` | `getStateStorageKey` |
| `shortcutKeycaps` (`/actions`) | `getShortcutKeycaps` |
| `getMenuChildren` (`/actions`, async) | `loadMenuChildren` |
| `getLocaleSettings` (`/locale`) | `resolveLocaleSettings` |
| `observeLocale` (`/locale`) | `observePageLocale` |
| `getLabelSiblings` (`/locale`) | `getLabelFallbackKeys` |
| `getRegisteredTags` | `getConnectedTags` (it lists tags with a connected instance) |
| `DEFAULT_CATEGORIES` | `DEFAULT_LOG_CATEGORIES` |
| `DEFAULT_ENABLED_LEVEL` | `DEFAULT_ENABLED_LOG_LEVEL` |
| `ALL_GROUPS` | `ALL_OVERLAY_GROUPS` |
| `DEFAULT_CONTAINER_SIZES` | `DEFAULT_CONTAINER_LINES` (the boundary widths) |
| `observeKeyboardInset` / option `shouldObserveKeyboardInset` | `fitToVisibleViewport` / `shouldFitToVisibleViewport` |
| `applyArmedState` | `setDropActiveState` ([details](#armed-is-now-drop-active)) |
| `menuPresentationInputs()` (`/menu`) | `createMenuPresentationInputs()` |
| `menuPresentationOptions(config)` (`/menu`) | `getMenuPresentationOptions(config)` |
| `getGlobalLogging` / `GlobalLoggingControls` | `getPageLogging` / `PageLoggingControls` |
| `createStyleSlot` / `StyleSlot` / `StyleSlotOptions` | `createStyleElement` / `StyleElement` / `StyleElementOptions` |
| `composedClosest` (internal) | `deepClosest` (now exported) |
| `isAtOrBelow` (internal) | `isDeepInside(el, container)` (now exported) |
| `callSafely` (internal) | `runSafely` (now exported) |
| `notifyEach` (internal) | `notifyListeners` (now exported) |
| `RenderLoaderCallback` | `RenderLoadingCallback` (it types the `renderLoadingCallback` input) |
| `Selection` / `SelectionMode` | `KeySelection` / `KeySelectionMode` ([details](#selection-types-and-the-multiple-mode)) |
| `toLogLevelNumber` | not exported any more ([details](#removed-exports)) |

### `setAttributes` is now `setProperties`

`el.setAttributes(values)` read like a bulk `setAttribute()`, but it always took property names (or their attribute
names) and values of any type and ran them through the input pipeline in one batch. It is now
`el.setProperties(values)` — same semantics, same return value (the rejections). Inside a component: protected
`engineConfig(exclude?)` → `getEngineConfig(exclude?)`, protected `runHook()` → `runCallback()` (it runs a consumer
`*Callback`).

```ts
// rc25
el.setAttributes({ 'selection-mode': 'multiple', items });
// rc26
el.setProperties({ 'selection-mode': 'multiple', items });
```

### Options-bag hooks are `*Callback`

Rule D-NC-26: `on*` is reserved for an event twin (`el.onReady`). A hook passed in an options object is a
`*Callback`.

| Factory / helper | Was | Now |
|---|---|---|
| `anchor()` (also via `createPopover` / `createTooltip`) | `onPlaced` / `onComputed` / `onDrift` | `placedCallback` / `computedCallback` / `driftCallback` |
| `createPopover()` | `onClose` | `closeCallback` |
| `openMenu()` (`/menu`), `createSheetHeader()` | `onClose` | `closeCallback` |
| `startModalSession()` / `startPanelSession()` | `onDismiss` | `dismissCallback` |
| `startSheetSession()` | `onBack` | `backCallback` |
| `animateOut()` | `onDone` | `doneCallback` |
| `createAsyncRunner()` | `onLoadingChange` / `onError` | `loadingChangeCallback` / `errorCallback` |
| `createCustomStyles()` | `onApply` | `appliedCallback` |
| `observePageDrag()` | `onChange` | `changeCallback` |
| `createPointerDrag()` | `onStart` / `onMove` / `onDrop` / `onCancel` | `beforeStartCallback` (`false` refuses the drag) / `moveCallback` / `dropCallback` / `cancelCallback` |
| `createActiveDescendant()` (`/a11y`) | `onActivate` / `onActiveChange` | `activateCallback` / `activeChangeCallback` |
| `createRovingFocus()` (`/a11y`) | `onFocusItem` | `focusItemCallback` |
| `prepareSearchTerm()` (`/search`) | `onObjectTerm` | `objectTermCallback` |
| `createSelection()` | `onChange` | `changeCallback` |

Unchanged: action items keep `onClick` (D-NC-27); positional parameters (`claimBackEntry(onBack)`,
`registerOverlay(onDismiss, …)`, `runner.run(task, onResult)`) are not option names.

### One entry point per symbol

Every runtime export now lives on exactly one entry point (a regression test enforces it). The main index is
regrouped into 13 commented sections — the reordering itself changes no export. Moves:

| Symbol | Was | Now |
|---|---|---|
| `createFocusTrap`, `getTabbables`, types `FocusTrap` / `FocusTrapOptions` | main index | `/a11y` |
| `escapeHtml` | main index and `/search` | main index only |
| type `ComponentContext` | main index and `/actions` | main index only |

`startModalSession` stays in the main index.

### Removed exports

Internal plumbing no component imported is no longer exported:

| Removed | Use instead |
|---|---|
| `resolveEnumAttribute(raw, values, fallback)` | a `toEnum` converter |
| `coreLogging` (lazy proxy) | `getCoreLogging()` |
| `toLogLevelNumber` | `isLogLevel` / `LOG_LEVELS` |
| `defaultEventProperty`, `normalizeEventDefs` | nothing — `BlissElement` event-table plumbing |
| `publishLoaderHook`, `publishIconHook`, `publishLocaleHooks` (`/locale`) | nothing — `registerComponent()` / `renderLoader()` / `renderIcon()` / the locale getters install the `window.components.*` accessors as before |
| type `ScrollLockState` | nothing — the shape stays documented in SPEC §12.9 |

### Selection types and the `multiple` mode

`Selection` and `SelectionMode` shadowed the lib.dom globals (`window.getSelection()`, `setRangeText`'s
`SelectionMode`) in any module that imported them. They are `KeySelection` and `KeySelectionMode` now, and
`createSelection`'s mode values are `'single' | 'multiple'` (was `'multi'`), matching `selection-mode` and the HTML
`multiple` attribute. Any value other than `'single'` still means multiple at runtime, so only the type check flags
`'multi'`.

### `createStateStore` takes one `getConfig`

`getKey()` / `getLoadCallback()` / `getSaveCallback()` become one `getConfig()` returning `{ storageKey,
loadStateCallback, saveStateCallback }` (type `StateStoreConfig<S>`) — the rulebook C-CA-17 input names, so a
component passes its config. Read on every call; empty / `null` key = off, no callback → `localStorage`, as before.
The app-facing inputs are unchanged.

```ts
// rc25
createStateStore({
  getKey: () => this.config.storageKey,
  getLoadCallback: () => this.config.loadStateCallback,
  getSaveCallback: () => this.config.saveStateCallback,
});
// rc26
createStateStore({ getConfig: () => this.config });
```

### `armed` is now `drop-active`

"Armed" was the interact.js term. A drop target that files hover over the page now carries the `drop-active`
attribute and `:state(drop-active)` (was `armed`), set by `setDropActiveState(host, internals, isDropActive)`;
`observePageDrag`'s change callback receives `isDropActive`. Rename the CSS selectors in the component and tell its
users in the component's own notes — this one reaches page CSS.

## Behaviour changes

### `startModalSession` dismisses the page's overlays

When a modal opens (a component's own panel, `/dialog`, the `/menu` phone sheet), open dropdowns, popovers and
menus in the **default** overlay group close, so nothing floats over the inert page. Never closed: the chain the
session's `trigger` sits in (a sheet opened from a dropdown row keeps the dropdown), overlays opened inside the
modal afterwards, and named overlay groups. Opt out with `startModalSession(panel, { shouldDismissPageOverlays:
false })`. Underneath: the `registerOverlay()` handle gains `activate({ dismissGroups })`.

### Tooltips hide on scroll

`createTooltip()` gets `shouldHideOnScroll` (default `true`): while shown, a scroll of the page or of a container
around the target (also across shadow roots) that moved the target hides it — the rule `createPopover({
shouldCloseOnScroll })` already used. A scroll inside the tooltip, of an unrelated scroller, or one that didn't move
the target never hides it. A tooltip shown by keyboard focus stays (WCAG 1.4.13). Before, a hovered tooltip trailed
its scrolling row (or a recycled virtual row); `shouldHideOnScroll: false` restores that.

### A missing label shows its key

`labels.text()` / `html()` with a key that has neither a built-in `DEFAULT_LABELS` entry nor a per-call `fallback`
now renders the key itself (was `''`), so a missing text is visible instead of a blank spot. Add the default or
pass `{ fallback }`.

### The `/menu` phone sheet is modal

The phone sheet / drawer of `openMenu` now runs through `startModalSession` (rule C-CA-19): the page behind — the
opener too — is `inert`, Tab stays between the shown level and the close button (it no longer closes the sheet),
Escape goes up one drilled-in level, else closes; scroll lock, Back and the backdrop as before. Focus returns to
`returnFocusTo`, else to what had it when the sheet opened. The floating menu is unchanged.

### `createAsyncRunner` `run()` returns a boolean

`run()` returns `true` when the task started or was scheduled and `false` when refused — only with the new
`concurrency: 'exclusive'`. The default `'latest'` mode always returns `true`.

### `toObject` accepts `null` without a default

Like nullable `toText` / `toInt` / `toEnum`: with no default, `el.labels = null` now clears the input (stored
`null`, forwarded by `getEngineConfig()`) instead of warning, keeping the old map and firing `input-rejected`. With a
default (converter or row), `null` is still refused; `el.x = undefined` resets.

### `bindShortcuts` `isEnabled` gets the event

`isEnabled?(event: KeyboardEvent)` is asked only for the binding that matched the key (it was asked with no
arguments for every binding on every key). `false` skips the binding **without** consuming the key (no
`preventDefault()`), so an outer `bindShortcuts` on an ancestor gets it — e.g. `isEnabled: (e) => !isTypingTarget(e)`.

## New features

### Icon maps

Icons work like labels. `renderIcon` order, maps first: markup → the element's `icons` map → the page-wide flat
`window.components.icons` (`'<tag>.<name>'` before `'<name>'`) → built-in name → the element's and the page's
`renderIconCallback` → the component's `defaults` → class names → text. A map can replace a built-in
(`{ close: 'fa-solid fa-xmark' }`); a name not in a map falls through. A component declares an `icons` row with
`toObject({ validate: isIconMap })`, `on: 'update'`; `iconsChanged()` also fires on a page map assignment.
`openMenu(…, { iconDefaults })` lets menu entries carry icon names. Demos DH09–DH15 in `examples-dom.html`.

### Copies that moved into core

- **`.km-sheet`** in `SHEET_CHROME_CSS` — the phone full-screen sheet frame (fixed `100dvw × 100dvh`, safe areas,
  modal tier, `.km-sheet-body` scroller, fade + rise, `--km-sheet-*` variables); replaces six component copies.
- **`createLayer(host, { customStylesOptions })`** (`/positioning`) — the component's page-wide and instance custom
  CSS inside its layer, kept live and removed on `destroy()`.
- **`createCustomStyles(…, { lintCssVars: { prefix, componentCss } })`** — the dev-only warning for custom CSS
  variables the component never reads, with "Did you mean …"; pass it only in dev.
- **`getInputDefaults(inputs, keys?)`** — each row's absent-attribute value, the one source for a public engine's
  defaults (C-CA-37).
- **`getCollator(locale?, options?)`** (`/locale`) — a cached `Intl.Collator` for the resolved locale; sort with it
  instead of a bare `localeCompare()`.
- **`createRovingFocus({ boundaryCallback })`** (`/a11y`) — asked when an arrow key finds no target; `true` = handled.
- **`createPointerDrag`**: `ctx.pressEvent` (the arming `pointerdown`, also on a touch long press) in every callback;
  `threshold` may be `(pressEvent) => number`.
- **`createAsyncRunner({ concurrency: 'exclusive' })`** — refuses a new `run()` while a task runs.
- **`labels.text(key, params, { fallback })`** — a per-call default for derived keys (type `LabelOptions`).
- **`deepClosest`, `isDeepInside`, `runSafely`, `notifyListeners`** (+ `SafeCallLog`, `SafeCallResult`) — the
  composed-tree and safe-call helpers, now exported.

## Fixes

- A keyboard-opened `openMenu` (Shift+F10 / the ContextMenu key) no longer lets the browser's late native
  `contextmenu` show over it or re-open the component's menu; a right-click or touch long press still opens.
- The first Escape on a tooltip shown by keyboard focus hides only the tooltip; an open dropdown under it stays
  open (WCAG 1.4.13). New read-only `TooltipHandle.isFocusShown`.
- CEM: `controller`, `on()` and `isLoggingEnabled` are listed in every component manifest — regenerate
  `custom-elements.json` to pick them up.
