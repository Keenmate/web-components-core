# Web Components Core 1.0.0-rc27 — Release Notes

**Released:** 2026-11-27 · **Pre-release** (`npm install @keenmate/web-components-core@rc`)

These notes cover the changes since **1.0.0-rc26**, the last version on npm. Upgrading from an older rc? Read the
[1.0.0-rc26](1.0.0-rc26.md) and [1.0.0-rc25](1.0.0-rc25.md) notes first.

rc27 is a small follow-up to the rc26 naming release: four internal verbs get their rulebook names (`dispatch*`,
`reconcile*`, **renamed outright, with no aliases**), built-in icons draw on a page without `base-css-variables`,
and the fallback colours follow the base-css-variables contract. **Apps on the released components need nothing**;
component authors apply the rename table below when they bump.

The exhaustive, per-change list is in
[`CHANGELOG.md`](https://github.com/KeenMate/web-components-core/blob/v1.0.0-rc27/CHANGELOG.md#100-rc27---2026-11-27)
(section 1.0.0-rc27); this document is the upgrade guide and the highlights.

## Upgrade checklist

**Component authors**

- [ ] Rename `notifyListeners` → `dispatchToListeners` and `notifyOverlayActivated` → `dispatchOverlayActivated`
      ([details](#internal-verbs-dispatch-and-reconcile)).
- [ ] `createLayer()` handle: `layer.syncTheme()` → `layer.reconcileTheme()`
      ([details](#internal-verbs-dispatch-and-reconcile)).
- [ ] `runAction()` option: `{ emitAction }` → `{ dispatchAction }` ([details](#internal-verbs-dispatch-and-reconcile)).
- [ ] Unit tests that asserted the icon span's inline style `--_km-icon: var(--base-icon-<name>)`: expect
      `--_km-icon: var(--_km-icon-<name>)` ([details](#built-in-icons-draw-without-base-css-variables)).
- [ ] Optional: drop your own fallback glyphs for built-in icon names — core draws them now
      ([details](#built-in-icons-draw-without-base-css-variables)).

**App developers**

- [ ] Nothing required: the renames reach you through each component's own release.

## Breaking changes

### Internal verbs: `dispatch*` and `reconcile*`

The rulebook (D-NC-30, check C-NC-16) keeps `notify*` for a message the user sees (a toast, an announcement) and
replaces `sync*` with `reconcile*`. No aliases; behaviour is unchanged.

| Was | Now |
|---|---|
| `notifyListeners(listeners, value, log)` | `dispatchToListeners(listeners, value, log)` |
| `notifyOverlayActivated(…)` | `dispatchOverlayActivated(…)` |
| `createLayer()` handle `syncTheme()` | `reconcileTheme()` |
| `runAction(item, ctx, { emitAction })` | `runAction(item, ctx, { dispatchAction })` |

## Visible changes without a migration

### Built-in icons draw without base-css-variables

`renderIcon('check')` and the other built-in names masked from `--base-icon-<name>` with a transparent fallback, so
a page without `base-variables.css` drew an empty 1em box. `ICON_CSS` now declares
`--_km-icon-<name>: var(--base-icon-<name>, <the contract SVG>)` for all 29 names (`clear` / `remove` fall back to
`close`), about 1.3 KB gzipped, and the icon span's inline style is `--_km-icon: var(--_km-icon-<name>)`. A page
`--base-icon-<name>` still wins. `check:contract` compares the copies with the contract byte for byte.

### Fallback colours follow the base-css-variables contract

Without `base-variables.css`, the `/menu`, the phone sheet / drawer chrome, `/dialog` and the `startModalSession`
backdrop look slate (the contract's defaults) instead of Fluent blue / grey: primary `#3b82f6`, danger `#dc2626`,
text `light-dark(#334155, #f1f5f9)`, dark surface `#1e293b`, scrim `rgba(30, 41, 59, 0.5)`. Derived tokens (border,
text-3, hover, elevated background, dropdown border / shadow, danger tint, input border) follow the contract
formulas, so they track `--base-main-bg` / `--base-text-color-1`; the menu background follows `--base-dropdown-bg` →
`--base-main-bg`. `npm run check:contract` runs in `prepublishOnly`. Pages that load `base-variables.css` see no
change.

## Fixes

- `/dialog` prompt field: `--base-input-size-md-height` is a unitless multiplier in the contract, but core used it as
  a length (setting it gave an invalid `min-height`). It's now `× --base-rem`, default 3.5.
