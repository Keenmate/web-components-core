# Web Components Core 1.0.0-rc25 — Release Notes

**Released:** 2026-11-22 · **Pre-release** (`npm install @keenmate/web-components-core@rc`)

These notes cover the changes since **1.0.0-rc24**, the last version on npm. 1.0.0-rc23 was never published;
it is already folded into the [1.0.0-rc24 notes](1.0.0-rc24.md), so nothing else is carried here.

rc25 is the consolidation release: the copies the seven Keenmate components kept of the same plumbing move into
core. Three new subpaths — `/locale` (page-wide locale, UI strings, numbers), `/a11y` (active descendant, roving
focus, typeahead) and `/dialog` (styled `confirm` / `prompt` / dialogs) — and on the main index modal / panel
sessions, virtual lists, selection, pointer drag, clipboard, IME-safe text input, icons, render-callback slots,
the controller facade, form inputs, async loading and screen-reader announcements. Every page-wide hook gets an
instance twin asked first. **For apps on the released components nothing is required**; component authors adopt
the new helpers, implement `iconsChanged()`, regenerate their manifests, and — if they built against the rc25 WIP
through a `file:` link — follow the label / icon reshapes made during the cycle.

The exhaustive, per-change list is in
[`CHANGELOG.md`](https://github.com/KeenMate/web-components-core/blob/v1.0.0-rc25/CHANGELOG.md#100-rc25---2026-11-22)
(section 1.0.0-rc25); this document is the upgrade guide and the highlights.

## Upgrade checklist

**Component authors**

- [ ] Bump to `^1.0.0-rc25`.
- [ ] A component that renders icons: implement the opt-in `iconsChanged()` hook (re-render the icons, keep the
      state) — `window.components.renderIconCallback` may be set after the component rendered
      ([details](#iconschanged-repaint-when-the-page-icon-hook-changes)). Rulebook C-CA-40.
- [ ] Icons: render icon strings through `renderIcon(icon, { prefix, host: this })` + `ICON_CSS`; a word name that
      isn't built-in (`'gear'`) now renders `<i class="gear">` — use a built-in (`'settings'`) or map it in
      `renderIconCallback`; a framework host passes `component` ([details](#icons-rendericon-keen-pure-admins-order)).
- [ ] Add the instance twins of the page-wide hooks as input rows: `renderIconCallback`, `translateCallback`
      ([details](#instance-twins-for-every-page-wide-hook)).
- [ ] A form-associated component: declare the `isRequired` row (attribute `required`, `toBool('presence')`,
      reflect), implement `isValueEmpty()` (+ `getRequiredMessage()` / `getValidityAnchor()`), call
      `refreshRequired()` on a value change; min / max counts → `rangeUnderflow` / `rangeOverflow`; never
      `internals.setValidity()` directly ([details](#isrequired-valuemissing-aria-required-staterequired)). Rulebook C-CA-41.
- [ ] Dynamic labels: pass the text spot's context, `labels.text(key, { ctx })`, and write the defaults as
      `{ctx.<field>}` with `ctx.count` = the number the noun agrees with
      ([details](#label-templates-read-the-spots-context-ctx)). Rulebook D-NC-24 (2026-11-22).
- [ ] Labels (if you built against the rc25 WIP): flat `<elementType>.<name>` keys, `createLabels(…, { tag:
      '<component>' })`, `formatLabelCallback` → `translateCallback` ([details](#labels-flat-keys-one-page-dictionary)).
      Rulebook C-CA-38 (`locale` input).
- [ ] A public engine without its element (web-command-palette, web-editor): `createLabels(null, defaults, getOwn,
      { tag, getTranslateCallback })` instead of a cast stand-in element or a private copy of the chain
      ([details](#createlabels-host-null)). Rulebook C-CA-39.
- [ ] A user callback's `ctx.labels`: pass `createLabelsView(labels)`, never a plain labels object
      ([details](#locale-page-wide-locale-labels-numbers)).
- [ ] Regenerate `custom-elements.json`: `blissAnalyzerConfig()` now runs `publicApiPlugin()` and keeps only the
      public API; `publicApiEntries` / `isPublicApiOnly: false` for other entry modules or the full output
      ([details](#cem-the-manifest-is-the-public-api)).
- [ ] Tooltips on `createTooltip`: drop your own tooltip opacity / transition / `@starting-style` rules —
      `TOOLTIP_CSS` fades every `.km-tooltip`; use `data-placement` for arrows / direction-aware CSS
      ([details](#tooltips-fade-out)).
- [ ] Number fields on `parseNumber`: a group separator outside a real group position (`'1.5'` in `de`) is now
      `null` — show your "invalid number" state; the third parameter is the logging `source` element
      ([details](#parsenumber-checks-group-positions)).
- [ ] A component that sets `valueMissing` (or another flag) itself: use `setValidityFlag(flag, message | null)`
      instead of `internals.setValidity()`; `setFormatError(null)` now clears only `customError`
      ([details](#setformaterrornull-clears-only-customerror)).
- [ ] Replace your own copies with the core helpers (`startModalSession` / `startPanelSession` /
      `startSheetSession`, `createVirtualWindow`, `createSelection`, `createActiveDescendant` /
      `createRovingFocus`, `createPointerDrag` / `watchPageDrag`, `createLayer`, `copyText`, `onTextInput` /
      `isImeEnter`, `renderSlot`, `createControllerFacade`, `createFormInputs`, `createAsyncRunner`, `announce`,
      `createDebounce`, `createId`, `isRtl`, `Z_INDEX`, the `/actions` shortcut functions,
      `toInt` / `toFloat({ isNullable })`) ([details](#new-features)).
- [ ] Responsive thresholds of your own (`compact-below`, `@media (max-width: …)` for the component's width):
      move to the `container` axis of the responsive rules ([details](#responsive-the-container-axis)).

**App developers**

- [ ] Nothing required on the released components: core's changes reach you through each component's own
      release.
- [ ] `/menu` item icons given as a word (`icon: 'gear'`): use a built-in name or markup, or map the word in
      `window.components.renderIconCallback` ([details](#menu-item-icons)).
- [ ] Page-wide labels / translations: assign ONE flat dictionary of full keys to
      `window.components.locale.labels` (`'web-grid.buttons.add'`) and use `translateCallback` for your own i18n
      ([details](#labels-flat-keys-one-page-dictionary)).

## Breaking changes

### Icons: `renderIcon`, keen-pure-admin's order

`renderIcon` (new in this release, SPEC §12.33) was reshaped during the cycle; only code built against the WIP
notices. First match wins:

1. markup (`'<svg …>'`) → raw;
2. a built-in name (`BUILT_IN_ICON_NAMES`, the base-css-variables `--base-icon-*` glyphs) → masked from its token;
   reserved, the hooks never see it;
3. the element's own `renderIconCallback`, then the page-wide `window.components.renderIconCallback(name,
   { component, element, prefix })` → markup, or `null` = not mine;
4. other class names (`'fa-solid fa-folder'`) → `<i class="<prefix>__icon fa-solid fa-folder" aria-hidden="true">`
   (they printed as text before);
5. anything else → escaped text.

A one-word name that isn't built-in (`'gear'`, a page-invented `--base-icon-star`) is no longer masked: it renders
`<i class="gear">`. Use a built-in (`'settings'`) or map it in `renderIconCallback`. A framework component that
renders into a plain `<div>` passes `renderIcon(value, { component })` so `ctx.component` isn't `'div'`.

### Menu item icons

`/menu` items go through `renderIcon`. In rc24 an icon string was set as `innerHTML`, so a word (`'gear'`) showed
as the word. Now a built-in name is a glyph masked from `--base-icon-<name>`, another class name an icon-font
`<i>`, and the page / component `renderIconCallback` can supply markup. Markup and emoji render as before.

### Labels: flat keys, one page dictionary

`/locale` is new in this release; its label shape was settled during the cycle. Keys are flat
`<elementType>.<name>` (`buttons.add`, `tooltips.clearAll`, `ariaLabels.clearAll`, `placeholders.search`; types
`buttons`, `tooltips`, `ariaLabels`, `placeholders`, `headers`, `labels`, `messages`, `errors`, `menuItems`,
`columnHeaders`), and the full key is prefixed with the component name: `web-grid.buttons.add`.

| Before (WIP) | Now |
|---|---|
| `window.components.locale.labels = { 'web-grid': { … } }` | one flat dictionary of full keys (warns + ignored otherwise) |
| `formatLabelCallback(ctx)` | `translateCallback({ component, key, template, params, locale })` → text, or `null` / `undefined` = not mine |
| `FormatLabelCallback` / `LabelFormatContext` | `TranslateCallback` / `LabelTranslateContext`; `OwnLabels<L>` |

An instance's `labels` takes the short or the full key, and a key it set is never sent to `translateCallback`.
`createLabels(…, { tag })` is the key prefix: components pass their own name, so a custom tag still reads
`web-grid.*`. The old callback name warns and is ignored.

### `createLabels` host `null`

`createLabels(host, …)` accepts `host: null`: a public engine without its element passes `tag` +
`getTranslateCallback` and gets the same order (its own callback → the page-wide one; instance labels never sent).
web-command-palette and web-editor used a cast stand-in element or their own copy of the chain.

### CEM: the manifest is the public API

`/cem` `blissAnalyzerConfig()` adds `publicApiPlugin()` / `keepPublicApi()` after `stableOutputPlugin()`:
private / protected / `#…` / `_…` members, and the modules, declarations and exports `src/index.ts` doesn't
re-export, are dropped. Re-export chains are followed (a folder specifier → its `index.ts` → the files it
re-exports; extensionless / `.js` specifiers). web-treeview's manifest went from 19k to 12k lines (459 internal
members). `publicApiEntries` adds other entry modules; `isPublicApiOnly: false` keeps the full analyzer output.
Regenerate each component's `custom-elements.json`.

### `parseNumber` checks group positions

A group separator is accepted only in a real group position (first 1–3 digits, then 2–3, the last group 3):
`'1.5'` in `de` was read as 15 and is now `null`; `'1.234,5'` and Indian `'12,34,567'` still parse. The third
parameter is the logging `source` element.

## Behaviour changes

### `setFormatError(null)` clears only `customError`

It used to reset every validity flag, so it also cleared a `valueMissing` the component had set — and a component's
own `setValidity({})` cleared a format error. Use `setValidityFlag()` for the other flags.

### Tooltips fade out

`createTooltip` keeps a hidden tooltip mounted (`km-tooltip--hiding`, `pointer-events: none`) until its `opacity`
transition ends, then removes it; core adopts `TOOLTIP_CSS` (`@layer component`, `:where()` — component rules win)
with a fade + 4px slide on `--base-duration-fast`. Every tooltip element gets class `km-tooltip` (`TOOLTIP_CLASS`,
`TOOLTIP_HIDING_CLASS`). `data-motion="none"` / OS reduced motion → removed at once.

### `/menu`: right-to-left and shortcuts

- RTL comes from `isRtl(opener)` (the effective CSS direction), not only the nearest `[dir]` attribute — CSS
  `direction: rtl` and `dir="auto"` on Arabic / Hebrew text now mirror submenus.
- An item's `shortcut` is shown formatted for the platform (`'Mod+C'` → `Ctrl+C` / `⌘C`), and an open menu runs
  the item on a chord too, not only on a bare key.

## New features

### `iconsChanged()`: repaint when the page icon hook changes

Setting, replacing or clearing `window.components.renderIconCallback` after components rendered now signals them:
the opt-in protected `iconsChanged()` hook fires while connected (not on the first connect, not for the same
function), a change while detached fires on reconnect. Outside a BlissElement: `observeIconHook(listener)`. Works
across bundled core copies; an rc24-or-older copy's accessor is taken over.

```ts
protected override iconsChanged(): void { this.#renderIcons(); }
```

### Instance twins for every page-wide hook

The element's own `renderIconCallback` / `translateCallback` / `parseNumberCallback` is asked first (`null` = not
mine → the page-wide one), so one element needs no `window.components` setup.

### `/locale`: page-wide locale, labels, numbers

`window.components.locale` (`locale`, `dateFormat`, `timeFormat`, `weekStartDay`, separators, `labels`,
`translateCallback`, `parseNumberCallback`) and `window.components.security.shouldEscapeLabels`;
`createLabels(host, defaults, getOwn, { tag })` with `.text()` / `.html()`, number params locale-formatted;
`createLabelsView(labels)` for a callback's `ctx.labels`; unset `ariaLabels.x` / `tooltips.x` follow a customized
twin (`getLabelSiblings`); `getLocaleSettings` / `resolveLocale`, `getMonthNames` / `getWeekdayNames`,
`formatNumber` / `parseNumber` (+ `parseNumberCallback`); the opt-in `localeChanged()` hook.

### Label templates read the spot's context (`{ctx.*}`)

`formatLabel` resolves dotted paths — `{ctx.remaining}`, `{ctx.item.text}` (own properties at every step; a missing
step stays as written). A component passes the text spot's context as `labels.text(key, { ctx })` — the same object
the spot's existing `get*Callback` receives — so a template and a callback read the same fields. Numbers are
locale-formatted and, in `html()`, strings escaped at any depth; `translateCallback` gets `params.ctx` (numbers
raw), and `ctx.count` (the number the noun agrees with) lets ONE generic bridge pluralize every key:

```js
window.components.locale = {
  translateCallback: ({ key, params }) => {
    const options = { ...params, count: params.ctx?.count };
    return i18next.exists(key, options) ? i18next.t(key, options) : null;   // exists() needs count too
  },
};
```

Flat `{name}` params keep working. Core stays a formatter: plurals / select come from the app's library.

### `isRequired`: `valueMissing`, `aria-required`, `:state(required)`

A form-associated class whose input table has an `isRequired` row (attribute `required`) implements
`isValueEmpty()` (+ optional `getRequiredMessage()` — its `errors.required` label — and `getValidityAnchor()`) and
calls `refreshRequired()` when its value changes; core also runs it after every flush. While required, empty and
editable (never readonly / disabled — native semantics) the host has `valueMissing`, through `setValidityFlag` so
other flags stay. `internals.ariaRequired`, `:state(required)` and `aria-required` on the validity anchor (the
focused inner input, when its role allows it) follow `isRequired`. A class without the row is untouched.

### `/a11y` and `/dialog`

- `/a11y`: `createActiveDescendant` (focus stays in the input; `shouldHandleKeys: false` for ARIA only),
  `createRovingFocus` (one tab stop, RTL-aware, typeahead, scrolls its container never the page),
  `createTypeahead`.
- `/dialog`: `openDialog`, `confirmDialog`, `promptDialog` — styled, translatable, a bottom sheet on narrow
  screens; replaces `window.confirm` / `window.prompt`.

### Overlays

`startModalSession` (inert page, focus trap, backdrop, Escape / Back, scroll lock, `isOpenedByPointer` ghost-click
guard), `startPanelSession` (non-modal: Escape / outside click / Back), `startSheetSession` (scroll lock, keyboard
inset, Back, containing-block warning), `createFocusTrap` / `getTabbables`, `registerOverlay`'s
`beforeEscapeCallback` and `deactivate({ shouldReturnFocus })`, the `.km-drawer` preset, `Z_INDEX` tiers,
`createLayer` (`/positioning`) for drag ghosts and drop covers, and `createTooltip` delegated mode (`selector`,
content resolver, `beforeShowCallback`, `arrow`, `shouldToggleOnTap`, `data-placement`).

### Lists, drag, text, DOM

`createVirtualWindow` (+ `getPinned`, `listTop`, `computeVirtualRange`), `createSelection`, `createPointerDrag`
(touch long press, auto-scroll), `watchPageDrag` / `applyArmedState`, `keepScrollAcrossMove`, `copyText` /
`readPasteText`, `onTextInput` (+ delegated `selector`) / `isImeEnter`, `renderSlot` / `renderSlotHtml`,
`createControllerFacade`, `createFormInputs` / `formatFormValue`, `createAsyncRunner`, `announce`, `isRtl`,
`createId`, `createDebounce` / `createThrottle` / `createFrameScheduler`, `isMotionOff` / `readScrollBehavior` /
`readCssDurationMs` / `readCssLengthPx`, `createElementSizeObserver`, `createPerfLogger`.

### Element, inputs, actions

- `setValidityFlag(flag, message | null, anchor?)`: one validity flag at a time.
- `toInt` / `toFloat({ isNullable: true })`: absent / empty → `null`.
- `/actions` shortcuts: `parseShortcut`, `matchesShortcut`, `formatShortcut`, `shortcutKeycaps`,
  `isTypingTarget`, `bindShortcuts` — one syntax (`Mod+Shift+Z`, sequences `'g f'`).
- `anchor()`: `maxWidth` / `maxHeight` `{ cap }`, `referenceWidthVar`, `shouldRestorePlacement`.

### Responsive: the container axis

A third rule axis keyed by the component's OWN width — `narrow` < 480px ≤ `medium` < 768px ≤ `wide`, lines from
`--base-container-narrow` / `-medium` read at the element. Order in one map: `breakpoint` → `container` → `device`.
`ResponsiveContext` gains `container` and `width`. Demo: examples-responsive RS07.

## Fixes

- A rejected-input warning labels its value (`got:` on the property path, `kept:` on the attribute path).
- The form-validity anchor warning names the method that was called.
- A text label falling back to a twin with markup takes its text, not the tags.
- `openMenu` asks the component's `renderIconCallback` even when `host` is a layer in its shadow root.
- `createRovingFocus` never scrolls the page; `createActiveDescendant(el, el)` leaves the tab stop alone.
- `createPointerDrag`: per-press `longPressMs` / `threshold`, `autoScroll.isEnabled`, `longPressMs: 0` on touch.
- `createPerfLogger` caps kept spans (`maxSpans`, default 1000).
- `createCustomStyles({ shouldShareLayers: false })` for an extra root of the same host.
- `watchPageDrag`: Escape stays dismissed for the rest of the drag.
- `copyText`'s fallback restores focus inside a shadow root.
- `normalizeSearchText`: an ASCII fast path (about 100× faster on ASCII).
- `readCssLengthPx` resolves inside a `display: none` subtree.
- Sheet close chip: hover tint only with a real pointer, tint while pressed.
